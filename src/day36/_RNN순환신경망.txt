[순환 신경망]
    - Recurrent Neural Network
    - 컴퓨터가 데이터를 기억하고 앞에서 받은 정보를 활용하여 다음에 어떤 결과가 나올지 예측하는 딥러닝 모델
    - 예) "나는 오늘" 입력시 RNN이 앞에서 받은 정보를 기억하여 "공부" 또는 "여행" 등의 단어를 예측한다.
    - CNN 합성곱과의 차이
        CNN: 이미지(2차원), 특징(색, 모양) 찾기, 이미지 분석 및 분류, 순서 상관없이 데이터 입력
        RNN: 텍스트, 음성(1차원), 이전 데이터 기억하여 다음 예측, 문장 만들기, 순서(시계열/시간) 유지하며 데이터 입력

SimpleRNN
    - 가장 기초적인 단일 순환신경망 구조
    - 동작 구조: 데이터를 계산처리하고 다음으로 넘겨서(이전 값) 다음 입력과 같이 계산처리 및 반복

LSTM: Long Short-Term Memory
    - 중요한 정보는 오래 기억하고, 덜 중요한 정보를 잊어버리는 방법
    - 사용처: 많은 데이터와 데이터를 오래 유지할 때 - 긴 문자열, 감정 분석 등
    - 동작 구조: 게이트 3개(망각, 입력, 출력)이 존재한다.
        - 망각 게이트: Forget Gate, 필요 없다고 생각하는 데이터를 잊는 게이트 (Sigmoid 함수, 0: 잊기, 1: 기억하기)
        - 입력 게이트: Input Gate, 현재 데이터를 전달받아 계산하고 Sigmoid 결과에 따라 상태를 더할지 말지 결정
        - 출력 게이트: Output Gate, 출력값을 결정하고 최종 기억 결정

GRU: Gated Recurrent Unit
    - LSTM과 같이 중요한 정보는 오래 기억하고, 덜 중요한 정보는 잊어버린다.
    - LSTM보다 구조가 간단하며 빠르다.
    - 사용처: 조금 더 적은 데이터와 빠른 속도가 필요할 경우 - 실시간 처리, 모바일 등
    - 동작 구조: 게이트 2개(업데이트, 리셋)
        - 업데이트 게이트: 망각/입력 게이트를 모두 제어, 새로운 데이터를 얼마나 기억할지 또는 잊을지 결정
        - 리셋 게이트: 이전 데이터를 얼마나 반영할지 결정
계산식 기호
    h: 현재 시점의 상태값
    x: 입력값
    W: 현재 시점의 가중치
    V: 이전 출력에 대한 가중치
    U: 현재 입력값에 대한 가중치
    t: time step, 시퀀스 데이터의 연속적인 순서
    F: 망각 게이트, 정보를 기억할지 잊을지 결정
    I: 입력 게이트, 새로운 정보를 더할지 말지 결정
    O: 출력 게이트, 최종 출력 결정
        Sigmoid: 1 또는 0 출력으로 게이트를 열지 말지 결정
        tanh: 하이퍼볼릭 탄젠트, 데이터를 -1에서 1 구간 사이로 변환
    R: 업데이트 게이트 (현재 입력을 얼마나나 기억할지)
   Z: 리셋 게이트 ( 이전 데이터를 얼마나 기억할지)

[인코딩]
    - 컴퓨터가 글자나 단어를 숫자로 변환하여 컴퓨터가 이해하고 처리할 수 있도록 하는 방법
    - 원핫 인코딩: 현재 단어의 위치 1, 나머지 0
        - e.g. 나는[1, 0, 0], 딥러닝이[0, 1, 0], 재미있다[0, 0, 1]
        - 문제점: 문장이 길어지면 대부분이 0으로 채워져 희소 행렬이 되고, 메모리 낭비가 일어나며 이전 단어와의 유사도를 알기 어렵다.
    - 밀집 행렬: 0이 아닌 실수값으로 채워 표현, 메모리 낭비 적음, 단어 유사도를 알 수 있다 (Keras API)
    - 임베딩 레이어

[양방향 RNN]
    - 데이터를 앞에서도 뒤에서도 읽는 양방향 RNN 신경망
    - 순차적 RNN은 앞 데이터를 보고 예측하지만 양방향 RNN은 앞뒤 데이터를 보고 에측
    - 예) "나는 밥을 먹었다": "나는"과 "먹었다"를 학습하며 "밥"을 예측할 수 있다.

[유닛]
    - CNN의 뉴런과 비슷한 역할
    - LSTM 레이어는 여러개의 유닛(뉴런)으로 구성되고 각 유닛(뉴런)은 입력을 처리하고 출력하는 역할
    - 예) 32개라면 32개의 독립적인 유닛(뉴런)을 통해 각 데이터를 처리하고 패턴을 학습
        - 많으면 더 많은 학습과 표현 향상이 되지만 과대적합이 될 수 있어 적잘한 크기 필요 (128, 64, 32 주로 사용된다)

[스태킹 RNN]
    - 여러 RNN 레이어를 쌓은 순환신경망 구조, 복잡한 패턴 학습 가능
    - 기본적으로 RNN은 마지막 상태값만 출력하므로 이전의 출력상태는 무시한다.
    - return_sequences 속성을 True로 설정해서 레이어를 쌓을 수 있다.

[순환 드롭아웃]
    - 드롭아웃: 훈련 과정 중 일부 뉴런(유닛)을 무작위로 선택하여 일부 비율만큼 무작위로 비활성화하여 학습을 시키지 않도록 구성
    - 목적: 과대적합을 방지하고 무작위를 이용한 다양한 뉴런 조합의 학습을 하여 일반화된 성능 향상 기대
    - 순환 드롭아웃: RNN 드롭아웃 적용
        - recurrent_dropout: 순환 연결된 이전 타임스텝에서 출력된 데이터에 무작위로 비활성화
        - dropout: 입력되는 새 데이터에 드롭아웃 적용, 전체 입력 유닛 무작위로 비활성화
